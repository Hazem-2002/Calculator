# 🧮 Interactive JavaScript Calculator

A dynamic and interactive calculator web application built using HTML5, CSS3, and JavaScript.  
The project demonstrates advanced front-end functionality, allowing users to perform arithmetic calculations with flexible controls and live updates.

---

## Key Features

### Custom Arithmetic Logic
- Users can select **operation priority** (standard PEMDAS order) or **sequential execution** via **Radio Buttons**
- Supports dynamic calculation updates based on chosen logic

### Dynamic Sign Control
- Toggle numbers between **positive and negative** instantly
- Immediate reflection of sign changes in the calculation results

### Flexible Operator Handling
- Arithmetic operations update dynamically based on user input
- Supports addition, subtraction, multiplication, and division
- Real-time feedback as users type or change settings

---

## Technical Highlights
- Advanced **DOM Manipulation** for dynamic UI updates
- Event Handling for buttons, inputs, and radio selections
- Dynamic user interface with real-time calculation
- Modular and reusable JavaScript logic
- Practical implementation of front-end interactive functionality
